CHECKOUT A/B TESTING — PRODUCT ANALYTICS CASE STUDY

## PROJECT OVERVIEW

This project evaluates an A/B test for a redesigned e-commerce checkout call-to-action (CTA).

The experiment compares:

Control:

* Grey CTA: "Proceed to Checkout"

Variant B:

* High-contrast green CTA: "Buy Now — Free Returns"

The business question is:

Does the redesigned CTA increase conversion without negatively affecting revenue?

## EXPERIMENT

Test period: March 3–30, 2025
Total sessions: 10,000
Control: 5,000 sessions
Variant B: 5,000 sessions

## PRIMARY METRICS

* Conversion Rate (CVR)
* Revenue per Session

## SECONDARY METRICS

* Bounce Rate
* Add-to-Cart Rate
* Pages Viewed
* Funnel Conversion
* Time to Conversion
* Average Order Value (AOV)

## ANALYSIS

The analysis covers:

1. Data quality checks
2. Exploratory data analysis
3. Performance comparison by variant
4. Conversion and bounce rates by device
5. Conversion and bounce rates by marketing channel
6. Add-to-cart behaviour by device and channel
7. Funnel analysis
8. Statistical significance testing
9. Effect size and practical significance

## STATISTICAL METHODS

* Two-proportion z-test for conversion rate
* Mann–Whitney U test for revenue per session
* Effect size analysis
* Funnel conversion analysis

## KEY PRODUCT QUESTION

The experiment evaluates whether increased conversion translates into meaningful commercial value. 
Conversion performance is therefore assessed alongside revenue and funnel behaviour rather than in isolation.
